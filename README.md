# hxwl-11 眼科验光记录 · 验光核对台账

旧镜度数与本次验光分开记录，门店按统一规则核对是否换镜。

## 技术栈

React 19 + Vite 7 + TypeScript + 原生 CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5111

## 分层结构

- `src/ledger/types.ts`：数据结构（屈光参数、核对结果、台账版本）
- `src/ledger/rules.ts`：换镜判断规则（纯函数）
- `src/ledger/model.ts`：建档、修订、门店处置、版本派生
- `src/ledger/storage.ts`：localStorage 持久化（重开页面结果还在）
- `src/ledger/seed.ts`：初始示例台账
- `src/components/`：录入表单、版本卡片、台账列表
- `src/App.tsx`：页面组装与状态流转

## 换镜规则（命中即建议换镜并保留命中项）

1. 球镜相差 ≥ 0.50D
2. 柱镜相差 ≥ 0.50D
3. 原有柱镜 ≥ 0.50D 且轴位差 > 15°（按 180° 圆周取最小夹角）

规则所需数值缺项时该规则无法核对：有命中仍给换镜建议；无命中但有缺项判“无法判断”。空值不当作 0，不计为变化。

## 处置与版本

- 保存核对：双眼旧镜/本次的球镜、柱镜、轴位与核对结果（含命中项、缺项）一并固定入台账
- 暂不换镜：保留核对结果，登记复查日期，可继续修订或重新核对
- 确认换镜：核对结果与处方锁定，不可再改；后续调整基于该处方自动带入旧镜并新建版本（同 rootId 版本链）
